Meshy로 만든 전력 32종

항공모함부터 해병 소총수까지, 이미지 한 장에서 3D 모델을 만들고 웹에서 돌아가도록 폴리곤을 줄였습니다.

VIBE CODING

기획부터 검증까지 AI와 함께

기획서, 코드, 이미지, 성능 검증 하네스까지 AI와 대화하며 만들었습니다. 코드를 잘 몰라도 아이디어만 있으면 만들 수 있습니다.

ABOUT THIS GAME

HORMUZ · 54일의 전쟁

과거의 주요 분기를 먼저 선택해 시작 수치를 만들고, 매일 세 번의 국가안보회의 결정을 내립니다. 군사 결정을 고르면 상단 시점 RTS 전투로 넘어가 직접 부대를 지휘합니다. 전쟁은 최대 54일까지 이어지고, 협상은 12일차부터 가능합니다.

  • 과거 주요 사건 6단계 선택으로 시작 수치 결정
  • 하루 세 번 · 군사 · 외교 · 경제와 정보
  • 7종의 실시간 3D 전투와 5단계 적응형 난이도
  • 예산과 의회 표결 · 대통령 강행 처리
  • 통항 · 유가 · 지지 · 국제 · 확전에 따른 10가지 결말
FICTIONAL SIMULATION 가상 전략 시뮬레이션입니다

실제 지명과 공개된 사건을 바탕으로 했지만, 게임 속 사건과 수치와 결정은 교육과 오락을 위한 허구입니다. 실제 인물의 음성이나 얼굴 정면을 쓰지 않으며, 민간인 피해를 게임 목표로 삼지 않습니다.
