HORMUZ 구글 3D 지도 연동 실행안

실제 해안선·위성 지형 위에서 현재 Three.js 전함, 전투기, 선택 링, 미사일과 폭발 효과를 계속 쓰려면 Maps JavaScript API의 WebGL Overlay View를 기본 방식으로 채택한다.

현재Natural Earth 해안선과 로컬 Three.js 지형 메시
1차 목표구글 벡터 3D 지형과 현재 전투 객체의 동일 WebGL 합성
안전장치키·할당량·지원 오류 시 현재 로컬 지형으로 자동 복귀
결론: 구글 3D 지도를 단순 배경 이미지로 쓰지 않는다. 구글 지도와 게임 객체가 같은 카메라·깊이값을 쓰게 만들어 지형 뒤 가림, 실제 위경도 배치, 확대·회전을 일치시킨다.

1. 방식 비교

방식장점한계채택
Maps JavaScript API + WebGL Overlay View 현재 Three.js GLB·선택·전투 효과 유지, 위경도 좌표 변환, 지도 건물과 깊이 가림 카메라·입력·렌더 루프를 구글 지도 기준으로 이관해야 함 본 전투 권장
3D Maps + Model3DElement 실사형 3D 지형과 GLB 배치가 간단함 현재 파티클·미사일·다중 선택 시스템을 그대로 옮기기 어려움 브리핑·결과 화면 후보
Map Tiles API Photorealistic 3D Tiles 3D Tiles 렌더러에서 매우 자유로운 합성 가능 별도 렌더러·저작권 표시·비용·용량 부담이 큼 2차 검토

2. 사장님이 발급할 값 2개

  1. Google Cloud에서 결제를 연결하고 Maps JavaScript API를 활성화한다.
  2. JavaScript용 Map ID를 만들고 벡터 지도, 기울기·회전을 활성화한다.
  3. 브라우저용 API 키를 만들고 HTTP 리퍼러와 Maps JavaScript API로 제한한다.

3. 키 입력 파일

net/google-maps-config.example.js를 net/google-maps-config.js로 복사한 뒤 다음 두 값만 채운다.

window.HORMUZ_GOOGLE_MAPS_CONFIG = Object.freeze({
  enabled: true,
  apiKey: "발급한 API 키",
  mapId: "발급한 Map ID",
  language: "ko",
  region: "KR",
  provider: "webgl-overlay",
  fallbackProvider: "local-three"
});

4. 개발 적용 순서

  1. G0 범위 검증: 호르무즈, 바레인-카타르, 오만만, 부셰르 4개 전장에서 3D·위성 품질과 지형 제공 범위를 캡처한다.
  2. G1 지도 공급자 분리: 현재 로컬 지도와 Google 지도 모드를 동일 인터페이스로 묶고 실패 시 로컬 모드로 자동 복귀시킨다.
  3. G2 좌표 정본화: 유닛·미사일·카메라의 정본 좌표를 위도·경도·고도로 바꾸고 fromLatLngAltitude()로 Three.js 행렬을 만든다.
  4. G3 전투 합성: 구축함·전투기·헬기·TEL, 선택 링, 항적, 미사일, 폭발을 WebGL Overlay View에 올린다.
  5. G4 입력 이관: 드래그 다중 선택, 좌클릭 선택 해제, 우클릭 이동·공격, 40% 확대 제한을 지도 카메라와 충돌 없이 연결한다.
  6. G5 검증: PC·모바일, 4개 전장, 55fps 목표, 지도 저작권 표시, 키 오류·할당량 초과 폴백을 확인한다.

5. 중요한 기술 판단

  • Google 공식 범위 문서는 3D 자연 지형을 전 세계에 제공한다고 안내하지만, 건물·나무 같은 3D 표면 데이터는 별도 지원 지역에 한정한다. 따라서 호르무즈 산악·해안 고도는 기대할 수 있어도 도시 실사 밀도는 API 키로 직접 확인해야 한다.
  • 구글 3D 지형은 화면 품질과 좌표 기준을 제공하지만, 게임용 해안 충돌 폴리곤을 직접 제공하지 않는다. 구축함의 육지 관통 방지는 현재 고해상도 해안 마스크를 계속 사용한다.
  • 지도에 보이는 해안선과 충돌선의 오차는 G0에서 캡처 비교 후 해안 데이터를 고해상도로 교체해 줄인다.
  • 구글 로고와 지도 데이터 출처 표시는 제거하거나 HUD로 가리면 안 된다.
  • 지도 로드 실패가 전투 실패가 되지 않도록 로컬 Three.js 지형을 항상 남긴다.
  • API 키가 준비되기 전에는 실제 3D 지도 품질·호르무즈 지역 커버리지를 확정했다고 보고하지 않는다.
