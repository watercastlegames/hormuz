# HORMUZ 완료 상태 감사 — 2026-07-30

기준 버전: RTS v110 · 본편 v38  
판정 기준: `HANDOVER.md`, `HANDOVER-2026-07-29.md`, 실제 데이터·런타임·검증 도구

## 결론

**게임 전체가 모두 완료된 상태는 아니다.** 현재 본편 규칙 코어와 3D RTS 공통 시스템은 실행 가능하고, 9개 작전 중 7개가 실제 플레이 가능하다. 이번 작업에서 곡괭이산 제한 타격을 일곱 번째 플레이 가능 작전으로 완성했다. 아래의 2개 작전과 M3·M4 공개 패키징은 아직 남아 있으므로 완료로 표시하지 않는다.

## 사람 확인 또는 외부 설정이 필요한 항목

1. Firebase 신규 프로젝트 config 발급, Google 로그인 활성화, 도메인 승인, rules 게시.
2. `sidak.kr/autodev/GameCreator/hormuz/` 실배포.
3. M2 완성 톤과 M4 공개 직전 최종 컨펌.

Firebase가 준비되지 않아도 로컬 게임 개발은 계속할 수 있다. 다만 실제 최고점 랭킹의 보안 규칙 검증과 운영 배포는 프로젝트 config 없이는 완료 판정을 내리지 않는다.

## 이번 v110에서 완료한 누락

1. 곡괭이산·GBU-57·B-2 사실관계 조사와 표현 경계 문서화.
2. B-2 전용 편성, 0대 출격 차단, 한 대당 GBU-57 2발 제한.
3. 지하 진입부 2곳과 방공 TEL 3기 배치.
4. 실제 발사체 충돌과 목표 전용 승리 판정.
5. 전용 브리핑·결과 이미지.
6. Google 3D 기본 지형과 로컬 산악 폴백.
7. 본편 카드·사건·직접 미션 별칭·캠페인 작전 연결.
8. 전용 자동 검증과 기존 전체 회귀 검증 대상 등록.
