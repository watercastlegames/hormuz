트랙별 프롬프트로 후보 2개를 만든다 → 공식 플랫폼 원본을 staging/suno에 보존한다 → 무음 구간과 루프 경계를 점검한다 → 짧은 페이드와 목표 길이를 적용한다 → 처리 결과 CSV와 채택 이유를 남긴다 → 승인된 6개만 masters/bgm으로 이동한다. API 권한이 확인되어도 이 검수·백업 순서는 바꾸지 않는다.

SUPERTONE_API_KEY는 환경변수에서 읽고, 먼저 언어·성별·연령·지원 모델·감정 스타일로 후보 음색을 검색한다. 선택 JSON에서 5명의 voice_id가 확정된 뒤 sona_speech_2로 스테이징 생성한다. 실패 요청은 짧은 간격 뒤 지수형 재시도하며, 파일마다 인물·언어·대사·스타일·설정·크레딧을 매니페스트에 남긴다.
