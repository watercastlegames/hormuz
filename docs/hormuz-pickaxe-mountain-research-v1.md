# 곡괭이산 지하시설 타격 시나리오 고증 메모 v1

작성일: 2026-07-30  
적용 대상: `pickaxe_mountain` 3D RTS 시나리오

## 1. 결론

- **곡괭이산(Kuh-e Kolang Gaz La, “Pickaxe Mountain”)은 나탄즈 농축시설 자체가 아니다.** 나탄즈 시설 남쪽에 별도로 건설 중인 지하 복합시설이다.
- 공개 위성영상으로 다수의 출입구와 굴착은 확인되지만, **시설 용도·내부 배치·핵물질 또는 원심분리기 반입 여부는 IAEA가 확인하지 못했다.**
- 따라서 게임은 “나탄즈 핵시설 완전 파괴”라고 단정하지 않는다. 목표를 **“확인된 지하 진입부 2곳 봉쇄”**로 한정하고, 결과 화면에도 **내부 피해평가 미확정**을 명시한다.
- GBU-57 MOP는 30,000파운드급 대형 지하시설 관통탄이다. 미 국방부 공개 설명은 이 무기를 **B-2에서만 투하**한다고 명시한다.
- B-2는 전투기가 아니라 **스텔스 전략폭격기**다. 시나리오에서 일반 전투기·헬기·구축함으로 GBU-57을 운반할 수 없게 막는다.
- 2025년 6월 Operation Midnight Hammer에서 B-2 7대가 포르도와 나탄즈에 GBU-57 14발을 사용했다. 곡괭이산은 당시 타격되지 않았다.

## 2. 사실과 불확실성

| 구분 | 공개 확인 범위 | 게임 반영 |
|---|---|---|
| 위치 | 나탄즈 농축시설 남쪽의 별도 산악 지하시설 | “나탄즈 남쪽 곡괭이산”으로 표기 |
| 시설 성격 | 공사·터널 출입구는 확인, 내부 용도는 미확인 | “의심 지하시설”로 표기 |
| IAEA 검증 | 시설 내부 접근·검증이 이뤄지지 않음 | 브리핑과 결과에 미확인 고지 |
| 투발 플랫폼 | 공개 운용 기준 GBU-57은 B-2에서 투하 | B-2 최소 1대 필수 |
| 탑재량 | 2025년 실제 작전에서 B-2 7대·GBU-57 14발 | B-2 1대당 게임 내 2발 제한 |
| 효과 | 표적 구조·암반·신관 설정에 따라 달라짐 | “진입부 봉쇄”, 내부 파괴 단정 금지 |
| 민간·정치 영향 | 핵 관련 시설 공격은 확전·국제 지지에 큰 영향 | 성공해도 국제 지지 하락·확전 상승 |

## 3. 시나리오 규칙

1. 출격 가능 전력은 B-2 스텔스 전략폭격기만 사용한다.
2. B-2가 0대면 작전을 시작할 수 없다.
3. B-2 한 대는 GBU-57을 2발만 투하한다.
   - 공개 운용 사례상 한 대에 2발 탑재가 확인된다.
   - 실제 작전에서는 같은 핵심 진입축에 여러 발을 순차 투하하기도 했다.
   - 게임은 확인된 진입부 2곳에 1발씩 투하하는 조작 단순화이며, 한 발이
     지하시설 전체를 파괴한다는 의미가 아니다.
4. 목표는 지하 진입부 2곳이다. 주변 방공 발사 차량은 선택적으로 제압할 수 있지만 목표 수에는 포함하지 않는다.
5. 플레이어는 적 유도탄을 급기동으로 회피할 수 있다.
6. 성공 결과는 “진입부 봉쇄·내부 피해평가 미확정”으로 표시한다.
7. 실패 결과는 “관통탄 소진 또는 폭격기 손실”로 표시한다.
8. 실제 인명 피해·시신은 표현하지 않는다.
