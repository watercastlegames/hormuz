화면 구성서 — 자동으로 흐르는 전장, 손끝의 결정

3D 전장이 화면의 전부다. 전쟁은 방송처럼 자동으로 흘러가고, 플레이어는 떠오르는 선택 버튼으로만 개입한다. 전장은 호르무즈 해협의 실제 지도 위에 세운다 — 케심섬, 무산담 반도, 반다르아바스, 그리고 폭 2해리의 실제 통항 레인까지.

기획서 v0.5의 동반 문서 실좌표 검증 30개 지점 중급 폰 60fps 예산 내
SECTION 01

인터랙션 모델 — 자동 진행 전쟁 방송

한 줄 요약 — "보고 있으면 전쟁이 흐르고, 버튼이 뜨면 내가 대통령이 된다." 카드 손패·AP 관리는 화면에서 제거(내부 데이터로만 유지), 입력은 선택 버튼과 가벼운 미니게임뿐.

왜 이 모델인가 (홍보용 최적화)

링크를 누른 사람이 아무것도 안 해도 30초간 화려한 전쟁이 흐른다 — 이탈 장벽 0. 첫 선택 버튼이 뜨는 순간 관전자가 플레이어로 전환된다. 조작을 배울 필요가 없으므로 SNS 유입 트래픽에 최적. 스크린샷·화면녹화 어느 순간을 잘라도 그림이 된다.

SECTION 05

전장 꾸미기 — 화려함의 레시피

한 줄 요약 — 화려함은 물량이 아니라 발광의 규율에서 나온다. 어두운 황혼 바다 위에서 빛나는 것만 빛나게 — 8개 레이어로 조립한다.

  1. 하늘 — 걸프의 매직아워그라데이션 돔 (남색 → 지평선 호박). 본편은 황혼 고정, 재연 챕터는 야간. 조명 셋업 1벌로 최대 효과.
  2. 바다 — 단일 패스 셰이더64×64 플레인 1장에 버텍스 웨이브+프레넬+홀로그램 그리드+스캔 글로우를 한 프래그먼트에서 합성. 반투명 레이어를 겹치지 않는다(모바일 오버드로 함정 — 검증됨).
  3. 육지 — 로우폴리 실지형실 해안선 압출 + 무산담 피오르는 정점 노이즈로 벼랑 표현. 무광 다크, 능선만 림 라이트 — 바다의 빛을 돋보이게 하는 어둠 담당.
  4. 차트 라인 — 전술 정보의 미학TSS 점선 레인, 영해선, 등심선, 사거리 부채꼴, 배치 구역 링. 해도(海圖) 그래픽 자체가 장식이 된다.
  5. 도시 불빛 — 살아있는 세계반다르아바스·두바이·카사브 등 8개 클러스터, emissive 점 무리 + 은은한 명멸. 전쟁 중에도 세계는 켜져 있다.
  6. 유닛 + 글로우 — 화려함의 본체실루엣 로우폴리 위에 가산합성 글로우 스프라이트(모바일 블룸의 표준 대체 — 검증됨). 아군 청록·이란 호박·민간 백색. 유닛 아래엔 블롭 셰도우(그림자맵 대신 — 검증됨).
  7. 궤적·파티클 — 순간의 드라마미사일은 커스텀 리본 쿼드(페이드 통제)+발광 헤드, 요격 성공 시 백색 섬광 링. 폭발·연기·웨이크는 공용 파티클 풀 (동시 총 4,000개 상한 — 검증됨).
  8. 화면 밖 마감 — CSS 합성스캔라인·비네트·막(ACT) 색온도 틴트는 전부 CSS 오버레이 — WebGL 비용 0 (검증됨). 확전 상승 순간의 적색 플래시도 CSS.
